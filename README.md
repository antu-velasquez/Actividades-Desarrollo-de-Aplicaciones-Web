# Actividad 2: React y Redux.

Aplicación funcional para el control de tareas y metas personales. En esta fase se integra la lógica de negocio para gestionar el listado de actividades.

## Cómo ejecutarlo:
1. Abrir el proyecto en [PlayCode.io](https://playcode.io/react).
2. Asegurarse de agregar las dependencias: `react-bootstrap`, `bootstrap`, `redux`, `@reduxjs/toolkit` y `react-redux`.
3. Cargar los archivos: `App.jsx`, `index.jsx`, `store.js` y `styles.css`.

## Características:
* **Manejo de estados:** Uso de Redux Toolkit para agregar y eliminar tareas en tiempo real.
* **Sin persistencia:** Los datos se mantienen únicamente en la sesión actual (sin base de datos).
* **Diseño adaptable:** Formulario lateral en escritorio y ventana emergente en dispositivos móviles.
* **Estilos:** Diseño que utiliza componentes de React Bootstrap y CSS externo.
