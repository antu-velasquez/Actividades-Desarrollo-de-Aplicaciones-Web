# Actividad 3: Node JS y Express.

Servidor para manejar el listado de tareas y metas personales.

## Ejecución:
1. Instalar dependencias: `npm install`.
2. Iniciar servidor: `node index.js`.

## Características:
* **Rutas:** Permite ver, agregar y eliminar tareas o metas.
* **Seguridad:** Uso de API Key (`Authorization: ToDo2026`) para dar acceso.
* **Almacenamiento:** Los datos son temporales y se guardan en la memoria del servidor.
